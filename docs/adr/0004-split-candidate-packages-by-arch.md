# Split candidate packages by architecture

Candidate distribution ships two single-architecture DMGs, `GoGrip-arm64.dmg` (Apple Silicon) and `GoGrip-x86_64.dmg` (Intel), instead of one universal candidate: each architecture is archived, signed and packed on its own, and package verification rejects any binary that is not exclusively its package's architecture. Measured with the packaging recipe (ad-hoc signed, symbols stripped): 8,085,364 bytes (arm64) and 8,875,546 bytes (x86_64) against 16,659,223 bytes for a universal DMG built with the same recipe, so each user downloads roughly half while the two packages total only about 1.8% more than the universal image. This refines ADR-0002: the candidate is no longer universal, while ADR-0002's Developer ID-signed, notarized distribution form remains the release plan and is handled by a follow-up change, not rewritten here.
