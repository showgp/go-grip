# Proposal

## Why

macOS 用户需要从 Finder 选中目录或 Markdown 文件，一次右键操作即可启动本地预览并打开浏览器，而不必使用终端。现有 macOS App 是存在多项缺陷的遗留示例，Services 注册、会话身份、启动反馈及进程归属不能视为可靠基础，需要重新设计并实现宿主，同时修正必要的 Go 集成契约。

## What Changes

- 重新实现原生常驻菜单栏 App，无 Dock 图标或终端窗口；内置 Go 工具，支持 macOS 13+、Apple Silicon 和 Intel，用户无需安装 Go 或配置 PATH。
- **BREAKING**：以 macOS Services 替代遗留 Finder Sync 扩展及其专用打开链路，不随 App 发布旧扩展。入口为“选中目标 → 右键 → 服务 → 用 GoGrip 打开”，接受系统控制菜单位置及启用状态；首次启动提供操作与设置引导，不自动修改用户的服务偏好。
- 统一 Finder 服务和手动选择入口，接受目录与 Markdown 文件，包括权限允许访问的本地、外接及已挂载网络卷目标。目录默认递归且启用热重载，文件直接进入单文件预览；成功启动后请求默认浏览器打开实际预览 URL。空目录也保留会话并显示空状态，不提供高级启动配置界面。
- 支持多选并去重，超过 5 个不同有效目标先确认；部分失败不阻断其余目标，保留成功会话，一次汇总失败及不支持的项目，全部成功不额外提示。
- 规范化路径并解析符号链接，同一目标最多一个会话，重复打开复用服务并再次请求浏览器打开；保留用户选择的路径用于展示。父目录、子目录及文件分别拥有会话，不因包含关系复用；不承诺复用同一个浏览器标签页。
- 建立明确的会话归属：关闭浏览器不停止服务；支持停止单个或全部会话；App 正常退出、崩溃或被强制退出时，其预览服务也应结束，不遗留后台服务。重开 App 不自动恢复预览，子进程意外退出不自动重启，退出原因与状态必须可见。
- 提供紧凑菜单栏面板，包含运行会话、最近目标、手动选择、重新打开浏览器、复制 URL、停止及退出入口。跨启动保留最近 20 个目标，不存正文；清空历史不停止会话。登录启动默认关闭、可主动开启；简体中文和英文跟随系统语言，其他语言回退英文，覆盖面板、错误、引导与服务名称。
- 按实际目标申请必要文件权限，不默认要求完全磁盘访问、辅助功能或自动化权限。失败有明确原生提示，并在面板保留可查看信息；启动失败不得猜测或回退到固定端口。浏览器打开失败时保留可用会话，支持再次打开或复制 URL。
- 会话按确定的目标路径运行，不自动追踪移动或后台重连；发现删除、移动或卷断开造成的不可访问时明确报错，保留查看和停止入口，不误报为空目录。已知监视失败或覆盖不完整时显示热重载降级状态，仍可手动刷新。
- 允许为上述行为做必要的 Go 集成修改，限定于启动与状态反馈、实际监听地址、进程归属、退出协调和监视状态；App 启动的预览实际仅监听本机，独立 CLI 仍可正常使用。
- 本阶段交付完整功能及可用的 universal App/DMG 打包流程，并实际验证 Finder 入口、浏览器预览、会话复用、停止和异常退出清理。签名、公证及正式安装包验证另行安排，本阶段不宣称正式发布就绪。

## Non-goals

- 不要求右键菜单第一层或目录空白处入口；不保留遗留 Finder Sync 扩展及其专用转发兼容层。
- 不重新设计浏览器渲染界面，不增加启动参数配置界面，也不把非 Markdown 文件自动转换为父目录目标。
- 不做浏览器标签页跟踪、随标签页关闭停止或空闲回收；不自动恢复或重启会话。
- 不追踪目标移动，不做卷断开后的后台重连，不增加轮询兜底，也不承诺网络卷自动刷新始终可靠。
- 不绕过系统文件权限，不提供 App 预览的局域网共享，不自动启用服务或登录项。
- 本阶段不完成 Developer ID 签名、公证、正式安装包验证或发布；未签名候选包的系统信任提示不代表最终产品安装体验。
- 不在本变更中同步主规格或归档变更，不擅自推送代码或发布 Release；后续规划与实现仍按独立审批及单票流程推进。

## Capabilities

### New Capabilities

- `macos-finder-service`: Finder Services 的目标交接、目录与 Markdown 支持、批量确认与部分失败、首次使用引导及按需文件授权。
- `macos-preview-sessions`: 规范化目标身份、会话复用、启动和真实 URL、本机监听、进程归属与停止、异常状态及热重载降级。
- `macos-menu-bar-app`: 无 Dock 的原生会话面板、手动打开与恢复操作、最近 20 个目标、可选登录启动及中英文界面。
- `macos-app-packaging`: macOS 13+ universal App、内置 Go 工具、候选 DMG 打包与实际功能验收，明确正式签名公证阶段的边界。

### Modified Capabilities

无。当前 `openspec/specs/` 尚无已发布的 capability；已有代码与 ADR 是现状及决策依据，不替代后续批准的行为规格。

## Impact

- `macos/GoGrip/`、App plist 与本地化资源：重建宿主、Services 注册、面板、历史与登录启动；替换旧示例逻辑。
- `macos/GoGripFinderSync/`、Xcode 项目与 `macos/project.yml`：移除旧扩展及嵌入依赖，更新宿主构建配置。
- `cmd/root.go`、`internal/server.go`、`internal/listener.go` 及必要的热重载接口：完善宿主集成，纠正实际监听范围并反馈会话状态；不扩大为渲染器重构。
- `macos/Scripts/`、相关构建及发布流水线：生成内置双架构工具的 App 和候选 DMG；不得将候选产物描述为正式发布就绪。具体集成机制和依赖选择留待 design 审批。
- 相关 Go/Swift 行为测试、实际 Finder/浏览器与进程生命周期 smoke，以及安装、使用和故障说明需随实现更新；不能以编译或测试通过替代真实路径验证。
- ADR 0001 的 Services 路线与 ADR 0003 的目标身份原则保持一致；ADR 0002 的正式签名、公证和干净安装标准仍有效，仅按本次批准将该正式分发阶段暂缓。
